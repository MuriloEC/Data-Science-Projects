# 📈 Previsão de Vendas com ETL e Machine Learning

Projeto desenvolvido em Python para realizar:

- ETL de dados de vendas
- Análise temporal
- Treinamento de Machine Learning
- Previsão de vendas futuras
- Visualização gráfica dos resultados

  Com o arquivo Vendas - Ecommerce.xlsx

---

# 🚀 Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

---

# 📊 Objetivo

O projeto utiliza dados históricos de vendas de um e-commerce para prever os meses restantes do ano utilizando técnicas de Machine Learning.

A base contém informações como:

Data da venda
Categoria do produto
Quantidade
Preço unitário
Valor total
Método de pagamento
Canal de venda

---

# 🤖 Machine Learning

O modelo utilizado foi:

Linear Regression

📐 Lógica Matemática

A regressão linear segue a fórmula:

y=ax+b

Onde:

x → tempo
y → vendas previstas
a → tendência
b → interceptação

---

# 📈 Visualização

O projeto gera um gráfico comparando:

vendas reais
vendas previstas

Utilizando Matplotlib.
